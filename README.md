## Browser extensions

- [Tabentic](https://www.tabentic.com) - AI agent that works inside the Chrome tabs you pick. Reads, extracts and summarizes pages; shows a step plan and waits for approval before clicking, typing or submitting. Free plan. ([Chrome Web Store](https://chromewebstore.google.com/detail/mflkmacalibfeiopafmehigedobihcjg))
- [HARPA AI](https://harpa.ai) - Chrome extension for web automation, page summaries and monitoring.
- [Merlin](https://www.getmerlin.in) - AI assistant extension for summarizing pages, videos and writing.
- [Bardeen](https://www.bardeen.ai) - Browser automation extension with prebuilt workflows for sales and ops.

## AI browsers

- [Perplexity Comet](https://www.perplexity.ai/comet) - Browser with a built-in AI assistant that can browse and complete tasks.
- [Opera Neon](https://www.opera.com/neon) - Agentic browser from Opera.
- [Dia](https://www.diabrowser.com) - AI-first browser from The Browser Company.

## Developer frameworks

- [Browser Use](https://github.com/browser-use/browser-use) - Open-source library to let LLMs control a browser.
- [Stagehand](https://github.com/browserbase/stagehand) - AI browser automation framework built on Playwright.
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) - MCP server that gives AI assistants browser control through Playwright.
- [Skyvern](https://github.com/Skyvern-AI/skyvern) - Automates browser workflows with LLMs and computer vision.

## Automation tools

- [Browserbase](https://www.browserbase.com) - Headless browser infrastructure for AI agents.
- [Zapier](https://zapier.com) - App-to-app automation with AI steps.

## Safety tips

- Prefer agents that **show a plan and ask before acting**, especially for purchases, sending messages and deleting data.
- Only give an agent access to the **tabs or sites it needs**.
- Never let an agent type passwords or payment details for you.
- Check the extension's **privacy policy** and permissions before installing.
- Keep a **Stop** button within reach and review results before trusting them.
